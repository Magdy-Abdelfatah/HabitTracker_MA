# Habit Tracker 

Welcome to the Habit Tracker APP!

---
## What This App Can Do

### Create Habits
- Add your own custom habits  
- Choose whether they repeat daily or weekly  
- Use predefined example habits if you want to practice

### Track Your Progress
- Check off a habit for today or any past date since creation
- Daily habits → once per day  
- Weekly habits → once per ISO week  
- The app blocks future dates and duplicate check-offs

### See Your Streaks
- View all your habits
- Filter by daily or weekly
- See your current streak
- See your longest streak
- Compare the strongest daily & weekly streaks

### Easy Storage
Your habits are saved automatically in simple JSON files:
- **habits.json** → your real profile  
- **demo_user_habits.json** → demo mode  
- **test_habits.json** → used only for automated tests  

---
## Requirements

Before running the app, make sure you have:

- **Python 3.10 or newer**  
- No external packages required — the app works with Python’s built-in modules

You can check your Python version with:

```bash
  python --version
```

---
## How to Run the App
- Open your terminal
- Navigate to the project folder:

```bash
   python3 -m habittracker.main
```
- When the app starts, choose:

	• Real user → your real habits

	• Demo user → pre-filled practice habits

---
### Practising With Sample Data

If you want to practice without touching your real data:

	1. Start the app
	2. Choose Demo user
	3. You will find example habits such as:
	    •	Drink 4L Water
	    •	Learn Python
	    •	Yoga
	    •	Deep Clean (weekly)
	    •	Call parents (weekly)

### You can freely:
	• Add new habits
	• Delete habits
	• Check things off
	• View streaks

Nothing you do affects your real data.
